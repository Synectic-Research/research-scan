# research-scan data contracts

Generated by `research-scan schema --md`. Do not edit by hand.

Unknown keys are rejected everywhere: a typo in an agent-written file surfaces as `exit 2` with the offending path, not as a silently dropped field.

## Run scaffolding

Written by `init`, embedded everywhere else.

### RunInfo

Identity of one scan. Printed by `init` on stdout and embedded in every file.

| Field | Type | Required | Default | Notes |
|---|---|---|---|---|
| `run_dir` | string | yes | — | Path to the run directory, e.g. `research/scans/2026-08-18-kickoff`. |
| `slug` | string | yes | — | Short run name. |
| `date` | string | yes | — | Run creation date, `YYYY-MM-DD`. |
| `brief_path` | string | yes | — | Path to `brief.md` inside the run directory. |
| `defaults` | [Defaults](#defaults) | yes | — | — |

### Defaults

Run parameters written by `init`; command flags and `queries.json` may override them.

| Field | Type | Required | Default | Notes |
|---|---|---|---|---|
| `window` | [Window](#window) | no | all defaults | Default 36 months back → today. |
| `top` | integer | no | `10` | Papers to emit. ≥ 1 |
| `foundational` | integer | no | `2` | Of `top`, slots reserved for out-of-window classics. ≥ 0 |
| `domain` | `behavioral` · `cs` · `biomed` · `general` | no | `general` | Routing domain; the agent resolves `auto` itself. |
| `sources` | array of `openalex` · `s2` · `arxiv` · `pubmed` | no | `["openalex", "s2"]` | Sources the routing map selected. |
| `profile` | `quick` · `standard` · `deep` | no | `standard` | Cost/recall dial: per-query depth, pool cap, out-of-window total, gap round. |

### Window

Publication window, inclusive months. `to: null` means "up to today".

| Field | Type | Required | Default | Notes |
|---|---|---|---|---|
| `from` | string (pattern `^\d{4}-(0[1-9]\|1[0-2])$`) or null | no | `null` | Earliest publication month, `YYYY-MM`. |
| `to` | string (pattern `^\d{4}-(0[1-9]\|1[0-2])$`) or null | no | `null` | Latest publication month, or null for today. |

## queries.json — agent writes

The plan step's output. Read `references/plan-rubric.md` before writing this.

### QueryPlan

`queries.json` — the plan the agent writes before `retrieve` (spec §9.1, §10.1).

| Field | Type | Required | Default | Notes |
|---|---|---|---|---|
| `brief_summary` | string | yes | — | One paragraph restating the project in the agent's words. |
| `domain` | `behavioral` · `cs` · `biomed` · `general` | yes | — | Routing domain. Never `auto` — resolve it in the plan step. |
| `window` | [Window](#window) or null | no | `null` | Overrides the run defaults when present. |
| `sub_criteria` | array of [SubCriterion](#subcriterion) | yes | — | min length 3, max length 6 |
| `must_not` | array of string | no | empty | Exclusion phrases, enforced in code at word boundaries. Never NOT-terms in query text. |
| `queries` | array of [Query](#query) | yes | — | min length 6, max length 8 |
| `anchors` | array of [Anchor](#anchor) | no | empty | Papers the brief already names. Pinned into the pool and always seeded. |
| `round2` | array of [Query](#query) | no | empty | The gap round: queries written after `coverage`, against thin sub-criteria. Empty until the gap round; `retrieve --round 2` runs these and only these. max length 8 |

### SubCriterion

One decomposed dimension of the brief; screening and reranking both score against these.

| Field | Type | Required | Default | Notes |
|---|---|---|---|---|
| `id` | string | yes | — | Stable id, e.g. `C1`. |
| `name` | string | yes | — | Two or three words, e.g. `population/setting`. |
| `text` | string | yes | — | What would make a paper satisfy this criterion. |

### Query

One search query aimed at one research community's vocabulary.

| Field | Type | Required | Default | Notes |
|---|---|---|---|---|
| `id` | string | yes | — | Stable id, e.g. `Q1`. |
| `type` | `direct` · `terminology` · `mechanism` · `method` · `adjacent` · `contradictory` · `review` · `emerging` · `gap` | yes | — | What this query is reaching for. |
| `text` | string | yes | — | The query itself, ≤ 30 words. Exclusions never go here. |
| `mode` | `semantic` · `keyword` | no | `semantic` | `keyword` allows Boolean syntax. |
| `target_criterion` | string or null | no | `null` | Sub-criterion id this query is reaching for. Required on a `gap` query. |

### Anchor

A paper the brief already names. Pinned into retrieval and always used as an expansion seed.

| Field | Type | Required | Default | Notes |
|---|---|---|---|---|
| `title` | string or null | no | `null` | Exact-ish title; matched at ratio ≥ 95. |
| `doi` | string or null | no | `null` | Preferred: resolves without ambiguity. |

|---|---|---|---|---|

### ScreenScore

0 off-topic · 1 tangential · 2 relevant to ≥ 1 sub-criterion · 3 central.

| Field | Type | Required | Default | Notes |
|---|---|---|---|---|
| `cid` | string | yes | — | pattern `^[0-9a-f]{12}$` |

| `reason` | string | yes | — | At most 20 words. |
| `criteria_hit` | array of string | no | empty | Sub-criterion ids this paper satisfies. Required on any score ≥ 2; `coverage` counts them per criterion. Empty on pre-v0.2 files, which count as unattributed. |
